الـ Array والـ Linked List في الذاكرة

اسحب عشان تلف المشهد · السهم البرتقالي = next · التركواز = prev
اختار عملية وشوف اللي بيحصل في الذاكرة خطوة بخطوة.

    جدول الذاكرة (مرتب بالعنوان)

    إيه هو next و prev؟

    كل Node بتخزن حاجتين: البيانات ومؤشرات (pointers). المؤشر مش بيانات، هو عنوان Node تانية في الذاكرة بيقولك "الجار موجود هناك". وبالمؤشرات دي بتتربط العقد المتفرقة ببعض.

    Singly: datanext   Doubly: prevdatanext

    next (التالي)

    • بيشاور على العقدة اللي بعدي.
    • بيخليك تمشي قدام: cur = cur.next
    • آخر عقدة الـ next بتاعها null.
    • موجود في الـ Singly والـ Doubly.

    prev (السابق)

    • بيشاور على العقدة اللي قبلي.
    • بيخليك تمشي ورا: cur = cur.prev
    • أول عقدة (head) الـ prev بتاعها null.
    • موجود في الـ Doubly بس، وبيكلف مؤشر زيادة في كل عقدة.

    إزاي بيتعدلوا؟

    • إضافة Node اسمها n بين p و x: n.next = x الأول (عشان منفقدش الباقي)، وبعدين p.next = n. في الـ Doubly كمان: n.prev = p و x.prev = n.
    • حذف Node اسمها t: p.next = t.next، وفي الـ Doubly كمان t.next.prev = p.
    • لما تضغط إضافة أو حذف، المؤشر اللي اتغير بيتلوّن في جدول الذاكرة فوق وبتشوف السهم بيتحول في المشهد.
    • الـ prev بيخلي حذف عقدة معروفة O(1) لأنها عارفة السابقة بنفسها، بدل ما تدوّر عليها من الـ head.
